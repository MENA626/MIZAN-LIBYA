## الملخص التنفيذي | Executive Summary

**مِيزان** هي منصة قانونية رقمية متكاملة تعتمد على الذكاء الاصطناعي والتقنيات الحديثة لإعادة تعريف تجربة الخدمات القانونية في بيئة رقمية موحدة وآمنة. صُممت المنصة لربط الأفراد والمحامين ضمن منظومة متكاملة تُسهّل إدارة القضايا، طلب الاستشارات القانونية، تنظيم المواعيد، تبادل المستندات، ومتابعة الإجراءات المختلفة بكفاءة واحترافية.

تعتمد "مِيزان" على بنية برمجية حديثة وقابلة للتوسع، تضمن استقرار النظام وسرعة الأداء مع الحفاظ على أعلى معايير الأمان والخصوصية. وتوفر المنصة نظاماً مركزياً لإدارة البيانات والمراسلات، مما يضمن سهولة الوصول إلى المعلومات وتنظيمها بشكل دقيق.

يُعد **الذكاء الاصطناعي** أحد الركائز الأساسية في النظام؛ حيث تم دمج تقنيات متقدمة لفهم وتحليل المحتوى القانوني وتقديم تجربة فائقة الذكاء. تعتمد المنصة على خوارزميات الاسترجاع المعزز بالتوليد **(RAG)** التي تمكّن النظام من البحث داخل المصادر والوثائق المخزنة، وفهم سياق الاستفسارات قبل توليد الإجابات، مما يساهم في تحسين دقة النتائج وتقليل احتمالية ورود معلومات خارج السياق.

كما تستفيد المنصة من تقنيات **البحث الدلالي (Semantic Search)** التي تتجاوز البحث التقليدي بالكلمات المفتاحية، ليتم تحليل المعنى القانوني للاستفسار وربطه بالمحتوى الأكثر صلة داخل قاعدة المعرفة، مما يسمح بالوصول السريع للتشريعات والأحكام حتى عند اختلاف المصطلحات.

تتضمن المنصة أيضاً **"المكتبة القانونية الذكية"** التي تعمل كمركز معرفي رقمي يضم التشريعات واللوائح والمراجع المعتمدة، مع إمكانية البحث المتقدم والتصنيف الذكي للمحتوى. ويوفر النظام آلية متكاملة لإدارة العمليات المالية المرتبطة بالخدمات القانونية (رسوم الاستشارات، المدفوعات، وسجل المعاملات).

تسعى "مِيزان" لأن تكون أكثر من مجرد منصة إدارية؛ بل **مساعداً قانونياً ذكياً** يدعم المستخدمين والمحامين للتعامل مع البيانات بصورة أسرع وأكثر كفاءة، لتقديم تجربة قانونية رقمية حديثة تجمع بين الدقة، السرعة، والموثوقية.

## البنية الهندسية ومميزات النظام | Core System Architecture

### 1. مساعد ميزان الذكي (Mizan Smart AI Assistant)
القلب النابض للنظام، وهو مساعد قانوني افتراضي مبني على واجهة برمجة تطبيقات (OpenAI API). يعتمد على خوارزميات الذكاء الاصطناعي لتحليل استفسارات العملاء القانونية وتقديم إجابات دقيقة وموجهة لحظياً، مما يوفر الوقت والجهد ويمنح العميل توجيهاً مبدئياً قبل اللجوء للمحامي.

### 2. الخزنة الرقمية والمكتبة الذكية (Smart Digital Vault)
منظومة أرشفة مشفرة وعالية الأمان، توفر بيئة رصينة لحفظ وثائق ومستندات العملاء والمحامين على حد سواء. تضمن الخزنة التخزين المنهجي للملفات الحساسة، الحماية الصارمة من الوصول غير المصرح به، والاسترجاع اللحظي للمستندات المرتبطة بالقضايا.

### 3. منظومة الاستشارات والقضايا (Consultations & Case Management)
نظام متكامل يتيح للعملاء حجز استشارات قانونية (نصية أو مجدولة) مع المحامين، بالإضافة إلى لوحة تحكم مخصصة لمتابعة "قضيتي"، حيث يمكن للعميل تتبع حالة قضيته، الجلسات القادمة، والمستجدات التي يرفعها المحامي الموكل بكل شفافية.

### 4. دليل المحامين وإدارة الصلاحيات (Lawyers Directory & Roles)
سجل رقمي متطور يتيح للعملاء تصفح ملفات المحامين، تقييماتهم، وتخصصاتهم لاختيار الأنسب. في الخلفية، يمتلك النظام هيكلية دقيقة لإدارة الصلاحيات بين (العميل، المحامي، ومدير النظام) لضمان فصل البيانات وتوجيه سير العمل بفاعلية.

### 5. البنية التحتية للمدفوعات والسحابة (Payments & Cloud Infrastructure)
ربط برمجي متكامل مع بوابة الدفع (Plutu) لمعالجة المعاملات المالية، مع اعتماد منصة (Supabase) لإدارة قواعد البيانات السحابية بتقنية (Connection Pooling)، مما يضمن استقرار الاتصال وسرعة استجابة النظام.

## دليل النشر والتشغيل | Deployment & Containerization

لضمان استقرار بيئة العمل وتوحيد الإعدادات بين جميع أعضاء الفريق، تم تجهيز النظام للعمل بالكامل داخل حاويات Docker. يرجى اتباع الخطوات التالية بالترتيب لإعداد وتشغيل المشروع محليًا.

### الخطوة الأولى: استنساخ المشروع وإعداد ملف البيئة

قم بسحب الشيفرة المصدرية للمشروع من المستودع، ثم أنشئ ملف البيئة (`.env`) وأضف إليه جميع مفاتيح وخدمات الربط المطلوبة، مثل بيانات الاتصال بـ Supabase ومفاتيح OpenAI وPlutu وغيرها من الإعدادات الخاصة بالمشروع.

> **مهم:** بعد إنشاء ملف البيئة، اطلب من مالك المشروع أو المسؤول التقني تزويدك بملف `.env` المعتمد أو بالقيم المطلوبة لإكمال الإعدادات.

```bash
git clone https://github.com/MENA626/mizan.git
cd mizan
cp .env.example .env
```

### الخطوة الثانية: بناء وتشغيل بيئة المشروع

قم بتشغيل الأمر التالي لبناء الحاويات المطلوبة وتشغيل خدمات المشروع في الخلفية، بما يضمن تجهيز بيئة العمل بشكل كامل.

```bash
docker-compose up -d --build
```

### الخطوة الثالثة: تثبيت الاعتمادات وتجهيز التطبيق

بعد تشغيل الحاويات، قم بتثبيت جميع المكتبات والحزم البرمجية المطلوبة لإطار Laravel، ثم أنشئ مفتاح التشفير الخاص بالتطبيق.

> **تنبيه:** الأوامر التالية لا تقوم بإنشاء أو حذف أو تعديل أي جداول أو بيانات داخل قاعدة البيانات.

```bash
docker-compose exec app composer install
docker-compose exec app php artisan key:generate
```

بعد إتمام الخطوات السابقة سيكون المشروع جاهزًا للتشغيل والاتصال بالخدمات المهيأة مسبقًا وفقًا للإعدادات الموجودة في ملف البيئة.
