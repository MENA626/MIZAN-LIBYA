## <img src="./assets/icons/scale.svg" width="26" height="26" alt="" /> نبذة عن المشروع | Project Overview

**مِيزان (MIZAN)** منصة قانونية رقمية تهدف إلى جمع الأفراد والمحامين ضمن منظومة واحدة، وتسهيل إدارة القضايا وطلب الاستشارات وتنظيم المواعيد وتبادل المستندات ومتابعة الإجراءات.

صُممت المنصة ببنية قابلة للتوسع، مع إدارة مركزية للبيانات والمراسلات. كما توظّف تقنيات الذكاء الاصطناعي والاسترجاع المعزز بالتوليد **(RAG)** والبحث الدلالي لمساعدة المستخدمين على استكشاف الوثائق والمصادر القانونية ذات الصلة. وتضم مكتبة قانونية رقمية، إلى جانب وظائف لإدارة رسوم الخدمات والمدفوعات وسجل المعاملات.

> يقدّم المساعد الذكي معلومات وتوجيهًا أوليًا، ولا يُعد بديلًا عن استشارة محامٍ مختص.

## <img src="./assets/icons/sparkles.svg" width="26" height="26" alt="" /> المزايا الرئيسية | Core Features

- **المساعد الذكي:** تحليل الاستفسارات وتقديم إجابات أولية بالاعتماد على تكامل OpenAI ومصادر المعرفة المتاحة للنظام.
- **المكتبة القانونية الذكية:** تنظيم التشريعات واللوائح والمراجع وإتاحة البحث المتقدم فيها.
- **إدارة القضايا والاستشارات:** طلب الاستشارات، حجز المواعيد، ومتابعة حالة القضية والمستجدات.
- **دليل المحامين:** استعراض ملفات المحامين وتخصصاتهم وتقييماتهم.
- **إدارة الأدوار والصلاحيات:** فصل الصلاحيات بين العميل والمحامي ومدير النظام.
- **الخزنة الرقمية:** أرشفة المستندات المرتبطة بالقضايا وإتاحتها للمستخدمين المخوّلين.
- **المدفوعات:** دعم تكامل بوابة Plutu لإدارة رسوم الخدمات والمعاملات.

### مكوّنات النظام

1. **المساعد القانوني الذكي:** يتكامل مع OpenAI لمعالجة الاستفسارات، مع الاستفادة من البحث في مصادر ووثائق المعرفة المتاحة.
2. **المكتبة والخزنة الرقمية:** حفظ المستندات وتنظيمها وربطها بالقضايا، مع إدارة الوصول وفق صلاحيات المستخدمين.
3. **إدارة القضايا والاستشارات:** متابعة القضايا والمواعيد والمستجدات، وإتاحة طلب الاستشارات القانونية.
4. **دليل المحامين والصلاحيات:** استعراض المحامين وتخصصاتهم، وتحديد صلاحيات العملاء والمحامين ومديري النظام.
5. **المدفوعات والخدمات السحابية:** تكامل مع Plutu للمدفوعات واستخدام Supabase وPostgreSQL لإدارة البيانات.

## <img src="./assets/icons/rocket.svg" width="26" height="26" alt="" /> التشغيل محليًا | Getting Started

### المتطلبات

- Docker وDocker Compose
- Git
- ملف إعدادات البيئة الخاص بالمشروع

### 1. استنساخ المستودع وإعداد البيئة

<pre><code>git clone https://github.com/MENA626/MIZAN-LIBYA.git
cd MIZAN-LIBYA
cp .env.example .env</code></pre>

أكمل إعداد متغيرات البيئة المطلوبة، مثل بيانات Supabase ومفاتيح OpenAI وPlutu. احصل على القيم من مسؤول المشروع، واحفظها في ملف البيئة محليًا فقط. **لا ترفع ملف <code>.env</code> أو المفاتيح السرية إلى GitHub.**

### 2. تشغيل الحاويات

<pre><code>docker compose up -d --build</code></pre>

### 3. تثبيت الاعتمادات وإنشاء مفتاح التطبيق

<pre><code>docker compose exec app composer install
docker compose exec app php artisan key:generate</code></pre>

> الأوامر أعلاه لا تتضمن تنفيذ ترحيلات قاعدة البيانات (<code>migrate</code>).

بعد إكمال الخطوات، راجع إعدادات البيئة وتأكد من جاهزية الخدمات المتصلة قبل استخدام التطبيق.
