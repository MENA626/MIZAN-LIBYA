## 📝 نبذة عن المشروع (About Mizan)
**ميزان** هو تطبيق ويب متطور يعتمد على بنية **MVC**، تم تصميمه لرقمنة العمليات القانونية وتسهيل إدارة القضايا. يركز المشروع على تقديم تجربة مستخدم سلسة (User Experience) مع ضمان أمان البيانات وسرعة استجابة النظام، وهو ما يتماشى مع معايير تطوير تطبيقات الويب الحديثة في قسم تقنيات الإنترنت.
